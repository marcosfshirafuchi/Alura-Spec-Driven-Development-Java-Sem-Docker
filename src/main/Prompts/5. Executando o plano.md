## 3. Execução local sem Docker

**É expressamente proibido utilizar Docker durante todo o processo.**

O projeto deve ser executado diretamente no ambiente local, utilizando:

- Java na versão configurada no projeto.
- Spring Boot.
- Maven, conforme a configuração existente.
- IntelliJ IDEA ou terminal.
- Banco de dados configurado para execução local.

Regras obrigatórias:

- Não executar `docker run`.
- Não executar `docker compose`.
- Não criar containers.
- Não utilizar Testcontainers.
- Não exigir Docker Desktop.
- Não criar ambientes de teste baseados em Docker.
- Não modificar a arquitetura para introduzir dependências de Docker.

Caso o projeto possua configurações relacionadas ao Docker, verifique se elas são necessárias e mantenha a execução local independente dessas configurações.

Caso existam dependências externas, configure sua utilização localmente, respeitando a arquitetura do projeto.

Não substitua automaticamente o banco de dados original por H2 ou outro banco sem verificar a compatibilidade com os testes e as regras de negócio.

- Testes dos controllers.
- Testes dos services.
- Testes de repositories.
- Testes de segurança e autorização.
