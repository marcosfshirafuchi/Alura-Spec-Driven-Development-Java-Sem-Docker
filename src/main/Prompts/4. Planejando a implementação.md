# 4. Planejando a implementação

## Prompt de IA:

### Primeiro prompt:
monte um plano de implementação para a feature descrita pela spec de cancelamento de pedido.
As etapas de implementação são:
Criar os testes tanto de caixa branca quanto de caixa preta, utilizando o postman e só depois de todos os testes estarem criados vamos implementar o código.

### Segundo prompt:
Comece pelos testes e espere uma validação para seguir com a implementação do código em si.
